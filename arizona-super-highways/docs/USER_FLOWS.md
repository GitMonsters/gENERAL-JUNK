# User Flows - Arizona Super Highways

## 1. New User Onboarding
1. User discovers guide (physical or digital)
2. Download app or visit website
3. Age verification (21+)
4. Create account (email/phone)
5. Complete profile
6. Tutorial on passport/check-in system
7. First check-in incentive

## 2. Physical Passport Check-In Flow
1. User at Medusa Farms (or participating location)
2. Open Arizona Super Highways app
3. Tap "Scan QR" or use camera
4. Scan location QR code from passport/display
5. App verifies QR signature
6. Check-in recorded, stamp added to passport
7. Points awarded based on tier/location
8. Offer unlocked (if applicable)
9. Push notification of reward

## 3. Discovering Specials & Drops
1. User opens app, views map/feed
2. Location shows "Hot Drop" badge
3. Tap location or notification
4. View exclusive offer (may be tier-gated/hidden)
5. Tap "Claim" to add to wallet
6. Show QR at register to redeem
7. Staff scans/redemption tracked
8. Points/experience updated

## 4. Ordering with Dutchie Routing
1. User browses menu (via app)
2. Adds items to cart
3. Taps "Checkout" / "Order"
4. App detects user location
5. System routes to closest location with inventory
6. Shows selected location + ETA/delivery info
7. User confirms order
8. Order sent to Dutchie's POS via API
9. Order tracking in app
10. Notification on status updates

## 5. Social Sharing & Reviews
1. User visits location, checks in
2. Option to share photo/review
3. Take photo or select from gallery
4. Add caption, rating (1-5)
5. Tag location/products
6. Post to feed (public or friends)
7. Others can like/comment
8. Verified purchase badge if ordered through app

## 6. Secure Messaging
1. User wants to connect (business/event/vendor)
2. Find in directory or from event
3. Tap "Message"
4. Key exchange happens automatically (E2E)
5. Compose encrypted message
6. Send - only recipient can decrypt
7. Real-time delivery
8. Read receipts (optional)
9. Can block/report

## 7. Live Events & Video
1. User notified of live event
2. Browse Events tab or notification
3. Tap event -> "Join Live"
4. Age/tier verification if gated
5. Join video stream (WebRTC)
6. Can react/comment (moderated)
7. May unlock event-exclusive drop
8. Event recording available later (if permitted)

## 8. Business Onboarding (Admin)
1. Business applies to join network
2. Submit info, license, location
3. Admin review/approval
4. Receive welcome packet + QR codes for passport
5. Set up business profile
6. Add offers/deals
7. Connect Dutchie (if dispensary)
8. Train staff on check-in/redemption
9. Go live in guide + app

## User Personas

### "The Road Tripper"
- Travels AZ, wants to find deals along route
- Uses map to plan stops
- Collects stamps for bragging rights
- Wants exclusive road trip drops

### "The Local Regular"
- Visits Medusa Farms weekly
- Maximizes tier benefits
- Engaged in community/social
- Early adopter of drops

### "The Connoisseur"
- Interested in reviews, limited strains
- Follows brands/vendors
- Attends workshops/events
- Values education

### "The Business Owner"
- Wants exposure in print + digital
- Drive foot traffic via check-ins
- Track redemptions/analytics
- Connect with community
